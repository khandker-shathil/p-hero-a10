# Add project screenshots

Place actual application screenshots in this folder. Screenshots have not been generated or added yet.

Suggested filenames:

- `home.png`
- `public-lessons.png`
- `lesson-details.png`
- `user-dashboard.png`
- `pricing.png`
- `admin-dashboard.png`
- `mobile.png`

Use representative lesson content and hide personal emails, payment details, secrets, and private user content before capturing. Keep desktop captures at a consistent width; use a separate narrow capture for the mobile example.

After adding each file, open the root `README.md` and remove the `<!--` and `-->` around its matching image line. For example:

```markdown
![Digital Life Lessons homepage](docs/screenshots/home.png)
```

If you choose a different filename or format, update the image path in the root README to match. Commit the screenshot files along with the README.
